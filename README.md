# بات سیگنال — NewMe Capital

واچ‌لیست را روی تایم‌فریم یک‌ساعته اسکن می‌کند. وقتی قیمت به ستاپِ استراتژی رسید یا
به آن نزدیک شد، برای ادمین تصویرِ تحلیل‌شده و شواهد را می‌فرستد. اگر ادمین تأیید
کند، تحلیل و سیگنال در کانال منتشر می‌شود.

```
اسکن (هر 1h / 4h / 1d) ─► امتیاز ≥ آستانه؟ ─► عکس + شواهد برای ادمین
                                                 │
                         ✅ انتشار ◄─────────────┤
                         │                       └─► ❌ رد
                         ▼
     کانال: ۱) عکس + تحلیل   ۲) سیگنال (ورود، حد ضرر، سه تارگت) در پاسخ به آن
```

## استراتژی

سه شرط کنارِ خطِ روند، روی **کندلِ بسته‌شده‌ی یک‌ساعته**. خطِ روند پایه است و
بدونِ آن امتیاز صفر می‌ماند:

| شرط | امتیاز | جزئیات |
|---|---|---|
| خط روند صعودی | 30 | دو کفِ چرخشیِ ماژور (۶ کندل هر طرف)، هرکدام با واکنشِ ≥ ۲ ATR. از اولین برخورد تا الان هیچ کندلی زیرِ خط بسته نشده. کندلِ فعلی در فاصله‌ی ≤ ۰.۵ ATR از خط است. اگر فقط در حالِ نزدیک شدن است (≤ ۱.۵ ATR)، نصفِ امتیاز را می‌گیرد |
| فیبوناچی 0.618 | 25 | فیبو از کفِ موج (برخوردِ دوم) تا سقفِ بعدش کشیده می‌شود. سطحِ ۰.۶۱۸ باید ≤ ۰.۶ ATR با خط فاصله داشته باشد (تا ۱.۲ ATR نصفِ امتیاز) |
| واگرایی RSI | 25 | بینِ کفِ فعلی و یک کفِ ۸ تا ۶۰ کندل قبل. **معمولی**: قیمت پایین‌تر، RSI بالاتر. **مخفی**: قیمت بالاتر، RSI پایین‌تر، که روی خطِ روندِ صعودی رایج‌تر است |
| کندلِ برگشتی | 20 × قدرت | روی یکی از ۲ کندلِ آخر: پوشا و ستاره‌ی صبحگاهی ×1.0، چکش ×0.9، نفوذی ×0.85، انبرک ×0.75، هارامی و دوجی ×0.6 |

**هشدار** از امتیازِ ۷۰ (قابلِ تغییر). یعنی دست‌کم خط به‌اضافه‌ی دو شرطِ دیگر.
اگر هر چهار شرط کامل باشد، پیام «ستاپِ کامل» می‌گوید؛ وگرنه «نزدیک به ستاپ».

**پلن:**
- ورود: قیمتِ بسته‌شدنِ کندل.
- حد ضرر: زیرِ پایین‌ترینِ کفِ برخورد یا زیرِ خط، هرکدام پایین‌تر، به‌اضافه‌ی ۰.۵ ATR فاصله.
- تارگت‌ها: سقفِ موج، و اکستنشنِ ۱.۲۷۲ و ۱.۶۱۸.
- ابطال: بسته شدنِ کندلِ یک‌ساعته زیرِ خط.

⚠️ متنِ استراتژی «0.168» نوشته شده بود. سطحِ استانداردِ فیبوناچی **0.618** است و
همان پیاده شد. اگر واقعاً سطحِ دیگری منظور است، فقط `strategy.fib.level` را در
`config/default.json` عوض کن.

همه‌ی عددهای بالا در `config/default.json` تنظیم‌پذیرند. فروش (`/direction both`)
با همان منطق روی قیمتِ قرینه اجرا می‌شود.

## داده

اولویت: **LBank ← Binance اسپات ← Binance فیوچرز**. اگر صرافیِ اول نماد را نداشت
یا کمتر از ۱۵۰ کندل داد، سراغِ بعدی می‌رود. وضعیتِ فعلیِ واچ‌لیست:

| نماد | منبع |
|---|---|
| BTC, SOL, AVAX, AAVE, HYPE, NEAR | LBank |
| XAUUSD | LBank ‏`XAUT/USDT` (توکنِ طلا که قیمتِ اونسِ طلا را دنبال می‌کند) |
| MAGMA | LBank ندارد ← Binance فیوچرز |

نمادی که نگاشتِ خاص لازم دارد، مثلِ طلا، در `config/default.json` تعریف می‌شود.
بقیه با `/add` اضافه می‌شوند.

## دستورهای ادمین

```
/list                 واچ‌لیست و تنظیمات
/add SOL NEAR         افزودن (اول چک می‌کند داده دارد)
/remove SOL           حذف
/every 4h             فاصله‌ی اسکن: 1h · 4h · 1d — روی مرزِ ساعتِ UTC، یک دقیقه بعد از بسته شدنِ کندل
/threshold 70         حداقلِ امتیازِ هشدار
/direction long       long · short · both
/scan                 اسکنِ فوری + جدولِ امتیازها
/scan SOL             تصویر و شواهدِ یک نماد، حتی زیرِ آستانه، با دکمه‌ی انتشار
/status               آخرین اسکن، اسکنِ بعدی، هشدارهای در انتظار
/id                   شناسه‌ی عددی (برای ADMIN_IDS)
```

## راه‌اندازی

```bash
npm install
cp .env.example .env      # BOT_TOKEN، ADMIN_IDS، CHANNEL_ID
npm test                  # بدون شبکه
npm run scan -- --charts  # اسکنِ واقعی بدونِ تلگرام؛ تصویرها در out/
npm start
```

بات باید **ادمینِ کانال** باشد و اجازه‌ی ارسالِ پیام داشته باشد.

## Railway

۱. **Variables:** `BOT_TOKEN`، `ADMIN_IDS`، `CHANNEL_ID`.
۲. **Volume** با mount path ‏`/data`، و متغیرِ `DATA_DIR=/data`. بدونِ آن، دیسک با هر
   دیپلوی پاک می‌شود. واچ‌لیستی که با `/add` ساخته‌ای برمی‌گردد به پیش‌فرض، و
   دکمه‌ی هشدارهای قبلی «پیدا نشد» جواب می‌دهد.
۳. **Region: اروپا** (Settings ← Deploy ← Region). سرورِ آمریکا را Binance
   فیوچرز با خطای 451 رد می‌کند و MAGMA داده نمی‌گیرد. اسپات از آینه‌ی
   `data-api.binance.vision` می‌آید و محدودیت ندارد.
۴. **Replicas = 1.** تلگرام به هر بات فقط یک polling می‌دهد. دو نمونه یعنی خطای
   409. بات خطای 409 را صبر می‌کند و کرش نمی‌کند، ولی پیام‌ها بینِ دو نمونه پخش
   می‌شوند.
۵. دامنه‌ی عمومی و health check لازم نیست. این سرویس worker است و پورتی باز
   نمی‌کند.

اگر یکی از متغیرها خالی یا غلط باشد، بات در لاگ دقیقاً می‌گوید کدام، و با کدِ ۱
خارج می‌شود.
